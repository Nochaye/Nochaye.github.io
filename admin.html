在自己的电脑上管理内容

GitHub Pages 仅托管静态页面。请在仓库目录运行：

python scripts/server.py

打开终端打印的管理链接，即可添加、修改和删除真实 HTML 文件。操作完成后，按 README 提交推送。

需要 Python 3.10 或更新版本，无需安装其他依赖。管理服务只允许本机连接。
